### Реализованные модули

#### 1. core/formula_parser.py
**Функциональность:**
- Загрузка и парсинг JSON конфигурации
- Извлечение алгоритма, параметров, блоков, формул
- Анализ формул (параметры, агрегации, термы)
- Вывод статистики и детализации
- CLI тестирование

**Ключевые классы:**
- `FormulaParser` - главный парсер
- Методы: `parse()`, `analyze_formula()`, `print_analysis()`

**Результат тестирования:**
```
Схема: 1
Алгоритм: Тестовый алгоритм (TEST_ALG)
Параметры алгоритма: 2

Блоков: 1
Всего формул: 3

Кубы: CUB_OSP_1

Формулы:
  Всего: 3
  С параметрами: 1
  С агрегацией: 1
```

#### 2. core/term.py
**Функциональность:**
- Представление терма формулы
- Сечения с измерениями и фильтрами
- Извлечение cube_id из внутреннего представления

**Классы:**
- `ElementSelection` - элемент выбора
- `Slice` - сечение измерения
- `Term` - терм формулы

**Методы Term:**
- `get_cube_id()` - извлечь cube_id
- `get_measurements()` - получить измерения

#### 3. core/period_expr.py
**Функциональность:**
- Представление периодического выражения
- Хранение текста и даты окончания периода

**Классы:**
- `PeriodExpr` - периодическое выражение

#### 4. core/formula.py
**Функциональность:**
- Представление формулы расчета
- Извлечение левой/правой части уравнения
- Обнаружение параметров
- Получение ссылок на кубы

**Классы:**
- `Formula` - формула

**Методы:**
- `get_expression()` - получить выражение
- `get_lhs()` - левая часть
- `get_rhs()` - правая часть
- `has_parameters()` - есть параметры
- `get_parameter_names()` - имена параметров
- `get_cube_refs()` - ссылки на кубы

#### 5. core/block.py
**Функциональность:**
- Представление блока расчёта
- Параметры блока
- Receiver (куб с измерениями)
- Формулы в блоке

**Классы:**
- `BlockParam` - параметр блока
- `BlockReceiver` - receiver блока
- `Block` - блок расчёта

**Методы:**
- `get_receiver_cube()` - получить cube_id
- `get_formula_count()` - количество формул

#### 6. core/algorithm.py
**Функциональность:**
- Алгоритм FSIGHT
- Параметры алгоритма
- Блоки расчёта
- Плоский список всех формул

**Классы:**
- `AlgorithmParam` - параметр алгоритма
- `Algorithm` - алгоритм
- `FSIGHTConfig` - полная конфигурация

**Методы:**
- `get_block_count()` - количество блоков
- `get_total_formula_count()` - общее кол-во формул
- `get_formulas_flat()` - плоский список формул
- `get_cubes()` - все кубы
- `get_cube_to_formulas_map()` - куб → формулы

#### 7. core/measurements.py
**Функциональность:**
- Представление точек данных в кубах
- Контекст куба с измерениями
- Lookup значений в кубах

**Классы:**
- `ValueType` - тип значения (number, date, string, boolean)
- `MeasurementValue` - значение измерения
- `DataPoint` - точка данных
- `CubeContext` - контекст куба
- `DataLookup` - поиск значений

**Методы:**
- `CubeContext.from_cube_data()` - создать из данных
- `DataLookup.get_value()` - получить значение
- `DataLookup.set_value()` - установить значение
- `DataLookup.add_values_from_dict()` - добавить несколько значений
