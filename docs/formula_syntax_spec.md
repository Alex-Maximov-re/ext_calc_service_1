# FSIGHT Math Engine - Спецификация формул

## Обзор

Формулы в FSIGHT определяются в JSON конфигурации с двумя основными полями:
- `text` - человеко-читаемое представление формулы
- `text_inner` - внутреннее представление для вычислений

## Структура формулы

```json
{
  "name": "Формула расчёта1",
  "id": "OBJ3",
  "text": "Куб OSP 1!X = Куб OSP 1!Число|2017 + 1",
  "text_inner": "@_2:0[] + 1",
  "terms": [...],
  "period_exprs": [...]
}
```

## Синтаксис text (человеко-читаемый)

### Общий формат
```
[Куб!]Измерение|Фильтры [операторы] [Константы]
```

### Примеры:

1. **Простая операция:**
   ```
   Куб OSP 1!X = Куб OSP 1!Число|2017 + 1
   ```
   - `Куб OSP 1!` - префикс куба
   - `X` - название измерения/индикатора
   - `|2017` - фильтр по году
   - `+ 1` - арифметическая операция

2. **С параметрами:**
   ```
   Куб OSP 1!Без учета валюты|{Параметр Год (блок)}|{Параметр Год (блок)} = ... + 2
   ```
   - `{Параметр Год (блок)}` - динамический параметр
   - Несколько фильтров через `|`

3. **С агрегацией:**
   ```
   Куб OSP 1!∑Год + 3
   ```
   - `∑` - оператор агрегации (сумма)

## Синтаксис text_inner (внутренний)

### Общий формат
```
@<cube_key>:<cube_index>[<filters>] [операторы]
```

### Примеры:

1. **Базовая точка:**
   ```
   @_2:0[]
   ```
   - `@` - начало ссылки на куб
   - `_2` - ключ куба (восьмеричное представление)
   - `:0` - индекс куба в схеме
   - `[]` - массив фильтров (пустой)

2. **С фильтром по параметру:**
   ```
   @_2:0[]
   ```
   где `[]` может содержать:
   - `0` - фильтр по году (2017)
   - `param_id` - параметризованный фильтр

## Термы (terms)

Термы раскрывают внутреннее представление в детали:

```json
"terms": [
  {
    "n": 1,
    "text": "Куб OSP 1!Число|2017",
    "inner": "@_2:0[]",
    "self": true,
    "lag": 0,
    "slice": [
      {
        "dim": "Факты структуры хранения",
        "dim_id": "DICT_INDICATOR_DATA_TYPES",
        "dim_key": 2225,
        "kind": "list",
        "elements": [{"key": "1", "name": "Число"}]
      },
      {
        "dim": "Год",
        "dim_id": "DICT_YEAR",
        "dim_key": 2554,
        "kind": "list",
        "elements": [{"key": "0", "name": "2017"}]
      }
    ]
  }
]
```

### Поля терма:
- `n` - номер терма
- `text` - текст для отображения
- `inner` - внутреннее представление
- `self` - является ли самореферентным
- `lag` - лаг (сдвиг по времени)
- `slice` - массив сечений (измерения с фильтрами)

## Сечения (slice)

Определяют измерения и их значения:

```json
"slice": [
  {
    "dim": "Название измерения",
    "dim_id": "DICT_ID",
    "dim_key": 1234,
    "kind": "list",  // "all", "list", "range"
    "elements": [...]
  }
]
```

### Типы selection:
- `list` - список элементов
- `all` - все элементы
- `range` - диапазон

## Операторы

### Арифметические:
- `+` - сложение
- `-` - вычитание
- `*` - умножение
- `/` - деление

### Примеры выражений:
```
Куб OSP 1!Число|2017 + 1
Куб OSP 1!{Параметр Год} + 2
Куб OSP 1!∑Год + 3
```

## Агрегация

### Оператор ∑ (сумма):
```
Куб OSP 1!∑Год
```
- Суммирует значения по указанным элементам измерения

## Параметры

Параметры подставляются в фигурных скобках:
```
{Параметр Год (блок)}
{Параметр Период (блок)}
```

### Параметры могут быть:
1. **Глобальными** (алгоритма) - `ALG_PARAM_YEAR`
2. **Локальными** (блока) - `BLOCK_PARAM_YEAR`

## Календарные уровни

`calendar_level` - уровень календаря для формулы:
```json
"calendar_level": 1
```

## Периодические выражения

`period_exprs` - выражения для периодов:
```json
"period_exprs": [
  {
    "name": "Нр - Кр",
    "text": "Куб OSP 1!Число|2017 + 1",
    "end_date": "31.12.9999 00:00:00"
  }
]
```

## Правила вычисления

1. **Парсинг:** Разобрать `text_inner` на термы и операторы
2. **Подстановка:** Заменить параметры значениями
3. **Резольвирование:** Преобразовать термы в точки данных
4. **Вычисление:** Выполнить арифметические операции
5. **Агрегация:** Применить агрегации (∑, и т.д.)

## Пример полного расчета

### Входные данные:
- Точка: `CUB_OSP_1!Число|2017` = 100

### Формула:
```
text: Куб OSP 1!X = Куб OSP 1!Число|2017 + 1
text_inner: @_2:0[] + 1
```

### Расчет:
1. Извлечь терм: `@_2:0[]` → точка с фильтром год=2017
2. Получить значение: 100
3. Выполнить операцию: 100 + 1 = 101

### Результат:
```
Куб OSP 1!X = 100 + 1 = 101
```

## Обработка ошибок

- **Неизвестный куб:** Проверить наличие в dictionaries
- **Неизвестное измерение:** Проверить измерения куба
- **Отсутствие значения:** Вернуть null или ошибку
- **Некорректный синтаксис:** Валидировать перед парсингом
