# FSIGHT Math Engine v1.0 - ЗАВЕРШЕН!

Математический движок для расчета формул в платформе Форсайт (FSIGHT).

**Проект на 100% готов!** ✅

---

## Описание

Движок принимает конфигурацию алгоритмов в формате JSON, точки данных и рассчитывает результаты по всем формулам с генерацией отчета в формате Markdown/HTML.

**Дата завершения:** Октябрь 2024  
**Версия:** v1.0.0  
**Статус:** ✅ ЗАВЕРШЕНО

---

## Быстрый старт

```bash
# Установка
pip install -r requirements.txt

# Запуск расчета
python main.py TEST_ALG.json --data data.json --output report.md

# С визуализацией
python main.py TEST_ALG.json -d data.json -o report.md --visualize

# HTML отчет
python main.py TEST_ALG.json -d data.json -o report.html --format html
```

## Использование

### Входные данные

#### Конфигурация (TEST_ALG.json)
Содержит параметры алгоритма, блоки расчёта, формулы с термами и измерениями.

#### Данные для расчета (data.json)
```json
{
  "custom_values": {
    "Число|2017": 100.0,
    "Число|2018": 150.0,
    "∑Год": 250.0,
    "Без учета валюты|2018": 150.0
  },
  "params": {
    "Параметр Год (блок)": 2018
  }
}
```

### Командная строка

```bash
# Базовый запуск
python main.py TEST_ALG.json --data data.json --output report.md

# С визуализацией
python main.py TEST_ALG.json -d data.json -o report.md --visualize

# HTML отчет
python main.py TEST_ALG.json -d data.json -o report.html --format html

# JSON результаты
python main.py TEST_ALG.json -d data.json -o results.json --format json

# Показать справку
python main.py --help
```

## Форматы вывода

- **Markdown** (.md) - структурированный отчет с таблицами
- **HTML** (.html) - красивый веб-отчет
- **JSON** (.json) - сырые данные результатов

---

## Пример отчета (Markdown)

```markdown
# Отчет о расчетах FSIGHT

## Статистика
- **Всего формул:** 3
- **Успешно:** 3
- **С ошибками:** 0

## Блок 1: Блок расчёта1
### ✅ Формула 1.1: Формула расчёта1
Текст: Куб OSP 1!Число|2017 + 1
Шаги:
    Lookup Куб OSP 1!Число|2017 = 100.0
    100.0 + 1.0 = 101.0
Результат: 101.0
```

## Возможности

1. **Парсинг конфигурации**
   - Загрузка JSON файлов
   - Извлечение алгоритмов, блоков, формул
   - Статистика и анализ

2. **Вычисления**
   - Арифметические операции (+, -, *, /)
   - Lookup значений измерений
   - Агрегации (∑)
   - Подстановка параметров

3. **Оркестрация**
   - Анализ зависимостей
   - Топологическая сортировка (DAG)
   - Правильный порядок вычислений

4. **Визуализация**
   - Графы зависимостей (Graphviz)
   - HTML визуализация
   - Текстовые диаграммы

5. **Отчеты**
   - Markdown (структурированные таблицы)
   - HTML (красивое оформление)
   - JSON (сырые данные)

6. **Тестирование**
   - Unit тесты всех модулей
   - Интеграционные тесты
   - Автоматизация запуска
