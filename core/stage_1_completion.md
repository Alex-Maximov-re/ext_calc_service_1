### 3. Реализованные классы

#### Term (терм формулы)
```python
Term(n, text, inner, self_ref, lag, slice)
```
- n: номер терма
- text: текстовое представление
- inner: внутреннее (@_2:0[])
- self_ref: самореферентный
- lag: лаг
- slice: сечения (измерения с фильтрами)

#### Slice (сечение)
```python
Slice(dim, dim_id, dim_key, kind, elements)
```
- dim: название измерения
- dim_id: ID измерения
- dim_key: ключ измерения
- kind: тип выбора (list, all, range)
- elements: элементы выбора

#### Formula (формула)
```python
Formula(name, id, key, text, text_inner, terms, period_exprs)
```
- name: название
- id: идентификатор
- text: текст
- text_inner: внутреннее
- terms: термы
- period_exprs: периодические выражения

#### Block (блок расчёта)
```python
Block(seq, name, id, key, params, receiver, formulas)
```
- seq: последовательность
- params: параметры
- receiver: куб с измерениями
- formulas: формулы

#### FSIGHTConfig (конфигурация)
```python
FSIGHTConfig(schema, algorithm, blocks)
```
- schema: версия схемы
- algorithm: алгоритм
- blocks: блоки расчёта

#### DataPoint (точка данных)
```python
DataPoint(cube_id, cube_name, measurements, value)
```
- cube_id: куб
- measurements: измерения
- value: значение

### Детализация формул

**Формула 1 (OBJ3):**
```
Куб OSP 1!X = Куб OSP 1!Число|2017 + 1
Text_inner: @_2:0[] + 1
Терм: Куб OSP 1!Число|2017 → CUB_2
```

**Формула 2 (OBJ4):**
```
Куб OSP 1!Без учета валюты|{Параметр Год (блок)}|{Параметр Год (блок)} = ... + 2
Параметры: ['Параметр Год (блок)']
```

**Формула 3 (OBJ5):**
```
Куб OSP 1!X = Куб OSP 1!∑Год + 3
С агрегацией: ∑Год
```
