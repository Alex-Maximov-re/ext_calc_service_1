# Отчет о создании таблиц FSIGHT

## Цель
Создание таблиц на основе структуры кубов и словарей из JSON конфигурации алгоритмов FSIGHT (TEST_ALG.json)

## Результат

### Созданные файлы

1. **`extract_cubes.py`** - Скрипт для извлечения информации о кубах и измерениях
2. **`generate_tables.py`** - Скрипт для автоматической генерации всех таблиц
3. **`sql/create_cubes_tables.sql`** - SQL скрипт для создания таблиц кубов (пример)
4. **`sql/create_dictionaries_tables.sql`** - SQL скрипт для создания таблиц словарей (пример)
5. **`sql/generate_cubes_dictionaries.sql`** - Полный SQL скрипт со всеми таблицами и данными (19,383 строки)
6. **`sql/README.md`** - Документация по таблицам

### Структура БД

| Таблица | Строк данных | Описание |

### Пример словаря DICT_INDICATOR_DATA_TYPES

**Элементы:**
- 1: Строка (SYSTEM_ID: STRING)
- 2: Число (SYSTEM_ID: NUMBER)
- 3: Дата (SYSTEM_ID: DATE)

**Атрибуты элементов:**
- KEY: идентификатор элемента
- NAME: название
- ORD: порядок сортировки
- DB_DATA_TYPE: тип данных БД
- SYSTEM_ID: системный идентификатор
- IDENT: тип значения

## Автоматизация

Для пересоздания таблиц из обновленного JSON файла:

```bash
# Пересоздать все таблицы
python generate_tables.py
```

Скрипт автоматически:
1. Читает TEST_ALG.json
2. Извлекает все кубы и измерения
3. Извлекает все словари, элементы и атрибуты
4. Генерирует полный SQL скрипт

## Примечания

- Все SQL скрипты написаны для SQL Server (используются IDENTITY, VARCHAR(MAX))
- Для PostgreSQL потребуется адаптация (SERIAL вместо IDENTITY, TEXT вместо VARCHAR(MAX))
- Скрипты автоматически обрабатывают произвольное количество кубов и словарей
